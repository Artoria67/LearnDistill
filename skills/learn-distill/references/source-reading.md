# 资料读取与来源对应

只读取任务需要的材料，不预设所有文件格式都能直接解析。

| 输入 | 处理与核对 |
| --- | --- |
| 照片、截图、扫描件 | 直接查看原图或使用可用 OCR；检查顺序、方向、遮挡、上下标、分式与图表。看不清的位置保留不确定标记。 |
| PDF | 优先提取文本并核对相关页面图像；扫描 PDF 走图像/OCR。不能只读首页或搜索到的几处词语就总结整章。 |
| DOCX | 使用文档读取工具或 OOXML 解析正文、表格、图片和公式。纯文本提取可能遗漏 Word 公式、浮动图和文本框，需结合渲染结果。 |
| 旧版 DOC 等文档 | 使用现有 Office/LibreOffice 或可信转换能力；不可用时请用户导出 PDF/DOCX，不把二进制文件当纯文本。 |
| 网页和在线文档 | 优先用可用的连接器或浏览器读取正文、公式及图片；记录准确链接和访问到的范围。遇到登录/付费限制，使用用户有权访问的内容或请其提供文件。 |
| 其他格式 | 根据实际可用工具处理。无法读取就明确说明该格式或内容缺项，并提出具体替代输入方式。 |

内部维护简短的来源对应表：来源文件/链接、页码或图片顺序、原文标题/题号、实际覆盖范围、不确定内容。成品只保留用户回查所需信息，不展示冗长处理日志。

原文标题、章节标题、题目、题号不可凭记忆重写。没有出现正式标题时，可以写明确标注为编辑拟定的标题，不能假称原文标题。输出语言与原文不同，保留原文标题并附译名；正文用目标语言。

缺页或片段：先交付可见部分，并在成品注明边界；随后询问是否需要补全。用户明确要求完整覆盖时，应尽早说明缺项并请求缺失材料，仍可先整理已提供部分。补全联网查询要核对书名、作者/版本（如可识别）、章节、题号与邻近内容；无法核实就标为“外部补充”，不合并成原文。

图表的处理目标是保留学习必需的信息。可从原文件提取、清晰裁切或重绘；重绘要保留单位、图例、坐标和原图编号。自制示意图标注“补充示意”，不可把示意图当原图。不要为“精简”删除关键图表，也不要把整页照片作为全部总结。

题目较长仍保留原题，后接精简解题说明。对仅要求知识点的任务不附加整章无关题目；对要求题解的任务不省略题目条件。用户要求和预算冲突时，说明保留条件带来的篇幅并协商范围。
